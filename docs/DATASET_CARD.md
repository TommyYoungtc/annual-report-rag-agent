# 数据集卡：上市公司年报语料

## 范围

- 宁德时代（300750）：2024、2025年年度报告；
- 科大讯飞（002230）：2024、2025年年度报告；
- 比亚迪（002594）：2024、2025年年度报告。

共3家公司、2个连续年度、6份公开披露文件。

## 来源

优先使用巨潮资讯网PDF；比亚迪2025年报告暂使用新浪财经公告镜像。
详细URL、文件名和来源记录在 `data/raw/manifest.jsonl`。

## 使用方式

PDF仅用于本地研究和实验，不提交到代码仓库。仓库保留下载脚本、公开URL、
SHA-256和解析统计，使其他人能够自行复现。

## 解析版本

### pypdf-baseline

- 逐页提取文本；
- 使用HTML注释保存页码；
- 优点：轻量、可复现、无需GPU；
- 缺点：复杂表格、双栏布局和扫描页效果有限。

### MinerU

- 作为高质量文档解析实验；
- 重点比较表格、标题层级、阅读顺序和OCR；
- MinerU结果与pypdf结果分别保存，不覆盖。

## 预期偏差

- 年报模板和行业语言差异可能使公司名称成为过强检索特征；
- 连续两年文档存在大量相似段落，适合构造hard negatives；
- 财务表格中的单位、合并口径和母公司口径容易混淆；
- 自动生成问题可能偏向容易检索的显式事实。

## 评测集约束

- 测试题必须由人工核验答案、证据页码和口径；
- 训练、开发、测试问题不得仅通过同义改写互相泄漏；
- 跨年份题必须同时标注两个年度的证据；
- 无答案题需确认6份报告中均不存在直接支持证据。
