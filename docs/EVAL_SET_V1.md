# 真实年报检索评测集 v1

## 范围

- 公司：宁德时代、科大讯飞、比亚迪
- 年份：2024、2025
- 语料：6 份年度报告，共 1,609 页、2,775 个文本块
- 问题：24 条，覆盖单事实、研发、员工、分红、跨年和跨公司检索

## 标注规则

1. 每个问题必须能从标注的文本块中直接找到答案。
2. `relevant_chunk_ids` 只标记包含直接证据的块，不标记仅有背景信息的块。
3. 跨年、跨公司问题要求召回所有相关块，因此比单事实问题更严格。
4. `answer` 和 `source_pages` 用于人工复核；当前检索指标只读取问题与相关块 ID。
5. 首版评测集规模较小，结果用于工程迭代，不应宣称为通用学术基准。

## 质量检查

- JSONL 每行可独立解析。
- 问题 ID 唯一。
- 所有相关块 ID 均必须存在于 `data/processed/pypdf_corpus.jsonl`。
- 答案数字与原报告的单位保持一致。

## 后续扩展

- 扩充到 80–120 条问题。
- 增加表格跨行、同义改写、否定条件和多跳问题。
- 由第二位标注者抽查至少 20%，记录一致率与修订原因。
