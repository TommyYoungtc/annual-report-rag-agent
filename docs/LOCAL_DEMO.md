# FastAPI 本地演示

## 定位

演示服务将现有受控流水线包装为可操作产品：

- 网页输入问题；
- 展示问题路由、答案或拒答原因；
- 展示计算过程；
- 展示公司、年份、Chunk、PDF页码和原文摘录；
- 展示本次请求是否使用GPU和端到端耗时。

项目依赖本地CUDA、RTX 4060以及约2.4GB模型文件，因此演示保持本地运行，不部署到普通静态
网站托管。

## 安装与启动

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[api]"
python scripts/run_demo.py
```

打开：

`http://127.0.0.1:8000`

可选参数：

```powershell
python scripts/run_demo.py --host 127.0.0.1 --port 8000
```

## API

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/` | 本地演示页面 |
| GET | `/api/health` | 服务状态和语料范围 |
| GET | `/api/scope` | 公司、年份和支持字段 |
| POST | `/api/query` | 执行受控年报问答 |
| GET | `/docs` | FastAPI交互文档 |

请求：

```json
{"query": "宁德时代2024年的营业收入是多少？"}
```

回答中的核心字段：

```json
{
  "status": "answered",
  "answer": "362,012,554千元",
  "reason": null,
  "citations": [
    {
      "chunk_id": "catl-2024:0009",
      "page": 9
    }
  ],
  "gpu_used": true
}
```

## 显存策略与并发

服务启动时只加载语料、BM25索引和已缓存文档向量，不立即加载模型。

1. 越界问题由CPU范围守卫直接拒答；
2. 有效问题加载Embedding模型完成查询编码和召回；
3. 卸载Embedding并清理CUDA缓存；
4. 加载Reranker完成Top-10重排；
5. 运行证据抽取、计算和引用；
6. 下一次有效请求再切换回Embedding。

GPU模型切换受线程锁保护，同一时刻只执行一个模型查询，避免8GB显存下的并发OOM。这个设计
优先保证本地稳定性，不追求高并发吞吐。

## 真实联调记录

环境：RTX 4060 Laptop 8GB，服务地址 `127.0.0.1:8000`。

| 问题 | 结果 | GPU | 端到端耗时 |
|---|---|---:|---:|
| 贵州茅台2025年营业收入 | 公司越界拒答 | 否 | 规则直达 |
| 宁德时代2024年营业收入 | `362,012,554千元`，第9页 | 是 | 13.67秒 |
| 宁德时代2025年海外研发投入 | 证据不足拒答 | 是 | 5.09秒 |

首次有效请求包含模型冷加载；后续有效请求仍需在Embedding和Reranker之间切换。页面与API的
功能测试使用替身模型，不把测试时间伪装成真实GPU延迟。

## 已知限制

- 当前仅适合单用户本地演示；
- 进程退出后模型需要重新加载；
- 未提供身份认证，不应监听公网地址；
- 不支持上传新PDF；
- 页面展示引用页码，但尚未嵌入PDF页图；
- 受控字段和证据限定词范围见 `docs/ANSWER_PIPELINE.md` 与
  `docs/HARD_NO_ANSWER.md`。
