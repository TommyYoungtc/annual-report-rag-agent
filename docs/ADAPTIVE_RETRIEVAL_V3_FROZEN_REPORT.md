# Adaptive Retrieval V3 独立冻结测试报告

## 1. 测试纪律

本轮测试在 Adaptive Retrieval 候选配置锁定后才选择公司和构造标签。三家测试公司为贵州茅台、
海尔智家和隆基绿能，与此前开发语料中的宁德时代、科大讯飞、比亚迪、海康威视、美的集团、
立讯精密和迈瑞医疗完全不重叠。

测试语料由三家公司 2024、2025 年共六份年报组成，合计 1,393 页、2,194 个 Chunk。测试集共
60 题：20 道单年度事实题、10 道跨年度比较题、8 道计算题、8 道年度/季度混淆题、6 道多证据题
和 8 道无答案题。答案、页码和 Gold Chunk 均逐题直接对照提取页文本核验；无答案题还对限定
公司和年份内的全部 Chunk 执行了约束匹配检查。

冻结时成功模型运行次数为 0。随后仅运行一次 A/B/C，脚本在结果写出后立即生成 Seal。结果
Seal 明确记录 `successful_frozen_test_runs=1`、`post_result_tuning_permitted=false`，候选锁、题集、
语料、PDF、向量缓存、生成脚本和执行脚本均由 SHA-256 固化。未根据测试成绩修改 Verifier、
Query Rewriter、模型、预算、阈值、语料或标签。

## 2. 三个系统

- A（Static RAG）：固定执行一轮混合检索、重排和受控回答。
- B（Always Agentic）：除终止型 Schema 拒答外，最多固定执行三轮检索。
- C（Adaptive / Budget-aware）：先评估当前证据是否充分，只在证据不足或年度/季度口径冲突时
  升级检索，最多三轮。

三者共享同一批问题、同一语料、同一 Embedding、同一 Reranker、同一回答器和同一检索轨迹，
只比较检索控制策略。

## 3. 一次性冻结测试结果

| 指标 | A Static | B Always Agentic | C Adaptive |
|---|---:|---:|---:|
| 全部任务正确率 | 66.7%（40/60） | 76.7%（46/60） | 76.7%（46/60） |
| 可回答题精确答案准确率 | 61.5%（32/52） | 73.1%（38/52） | 73.1%（38/52） |
| 无答案拒答准确率 | 100%（8/8） | 100%（8/8） | 100%（8/8） |
| 全部 Gold 证据 Recall@10 | 98.1%（51/52） | 98.1%（51/52） | 98.1%（51/52） |
| 引用 Chunk 精度 | 83.1% | 91.8% | 91.8% |
| 引用页码集合准确率 | 67.3% | 78.8% | 78.8% |
| 平均检索轮数 | 1.00 | 2.80 | 1.48 |
| 升级率 | 0% | 96.7% | 35.0% |
| 平均延迟 | 1.605 秒 | 4.778 秒 | 2.567 秒 |
| P95 延迟 | 1.974 秒 | 6.101 秒 | 5.393 秒 |
| 重排 Passage 总数 | 600 | 1,680 | 890 |
| 每个正确答案延迟成本 | 2.408 秒 | 6.232 秒 | 3.348 秒 |
| 每个正确答案重排 Passage | 15.00 | 36.52 | 19.35 |

全部推理在本地 RTX 4060 Laptop GPU 上完成，没有调用付费 API，因此估算 API 成本为 0 美元。
报告使用延迟和重排 Passage 数作为实际计算成本代理。三轮执行总墙钟时间为 311.99 秒；Reranker
峰值已分配显存约 1.79 GiB。

## 4. 分题型结果

| 题型 | 题数 | A Static | B Always Agentic | C Adaptive |
|---|---:|---:|---:|---:|
| 单年度事实 | 20 | 75.0% | 75.0% | 75.0% |
| 跨年度比较 | 10 | 50.0% | 90.0% | 90.0% |
| 计算 | 8 | 37.5% | 62.5% | 62.5% |
| 年度/季度混淆 | 8 | 62.5% | 62.5% | 62.5% |
| 多证据 | 6 | 66.7% | 66.7% | 66.7% |
| 无答案 | 8 | 100% | 100% | 100% |

C 共 39 题使用一轮、13 题使用两轮、8 题使用三轮。与 B 相比，C 在准确率完全相同的情况下，
平均检索轮数下降 47.0%，平均延迟下降 46.3%，重排 Passage 数下降 47.0%，每个正确答案的
延迟成本也下降 46.3%。与 A 相比，C 的全部任务正确率提高 10.0 个百分点，可回答题准确率提高
11.5 个百分点。

## 5. 检索升级真正解决了什么

C 相比 A 额外答对 6 题：4 道跨年度比较题和 2 道计算题。它们分别涉及贵州茅台、隆基绿能的
跨年净利润或经营现金流。第一轮曾选择季度值或证据不完整，Verifier 触发第二/第三轮定向检索
后找回全年值。这个结果支持本实验的核心假设：复杂检索不是每题都需要，但对证据口径冲突和
跨年证据不完整的问题确实有价值。

B 与 C 的最终质量完全一致，但 B 几乎对所有问题升级。C 只升级 35% 的问题，因此本轮结论不是
“Agentic Retrieval 总是更准”，而是“证据感知的升级策略能以约一半的检索成本达到 Always
Agentic 的质量”。

## 6. 冻结后的失败归因

C 仍有 14 道可回答题失败，但这 14 题的 Gold Chunk 全部已进入最终证据集合，说明主要瓶颈已
不在召回，而在字段识别、PDF 文本归一化和年度/季度证据选择：

- 3 道研发人员数量题把“研发人员数量占公司总人数的比例”误抽成 2.30、19.2、9.45 人，属于
  表格行边界和字段正则问题。
- 2 道研发投入金额/比例题因年报使用“研发投入合计”“研发投入总额占营业收入比例”，与锁定
  Schema 的字段标签变体不一致而拒答。
- 3 道海尔智家 2024 年净利润相关题受 PDF 表格中的汉字空格影响，虽然 Gold Chunk 已召回，
  受控抽取器仍未形成完整年度值。
- 2 道现金流计算题因问题省略“产生的”而没有命中锁定字段别名，触发 `unsupported_fact`。
- 2 道跨年净资产题在完整证据已召回的情况下仍拒答，属于跨 Chunk 表格抽取失败。
- 2 道隆基绿能 2024 年年度/季度混淆题仍选择了第一季度值，说明当前 Verifier 对“同一 Chunk
  同时含年度说明和季度表”的边界识别仍不稳。

名义上的唯一 Gold Recall Miss 是 `v3-frozen-test-052`：标注 Gold 为
`longi-2024:0015`，系统引用了相邻的 `longi-2024:0014`。后者同样包含完整的 2024 年基本每股
收益，且最终答案正确。因此 98.1% 是按冻结 Gold ID 计算的保守结果；为遵守冻结纪律，没有在
看到结果后追加等价 Gold Chunk 或重算指标。

## 7. 可以对外使用的结论

可以如实表述为：在三家开发阶段从未出现的新公司、60 题一次性冻结测试上，Adaptive Router
达到 76.7% 全任务正确率和 100% 无答案拒答率，与 Always Agentic 持平；同时将平均检索轮数、
重排量和平均延迟降低约 46%～47%。不能把 76.7% 写成“系统准确率接近 100%”，也不能把
98.1% 的证据召回率当作端到端答案准确率。

后续如开发新版本，应将本轮 60 题视为已污染的历史回归集。任何字段 Schema、空格归一化或
季度识别修复都只能在新的开发集上完成，并需另建一批从未参与开发的公司和问题做新的冻结测试。
