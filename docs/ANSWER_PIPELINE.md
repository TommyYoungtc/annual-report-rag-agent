# 证据回答、计算与引用流水线

## 流程

当前受控 Agent 已串起以下路径：

```text
问题路由
  → 公司/年份范围守卫
  → 元数据过滤
  → Qwen3-Embedding + BM25 + 加权RRF
  → Qwen3-Reranker Top-10
  → 年报章节消歧
  → 字段数值抽取 / Decimal计算
  → 答案 + Chunk + 页码 + 原文摘录
```

回答器只支持已声明的财务字段。公司、年份、字段、单位或页码证据不完整时返回结构化拒答，
不会从题目、评测答案或模型常识中补数。

## 当前支持字段

- 营业收入；
- 归属于上市公司股东的净利润；
- 经营活动产生的现金流量净额；
- 归属于上市公司股东的净资产；
- 研发投入金额及占营业收入比例；
- 年末在职员工总数、技术人员数量；
- 每10股现金红利；
- 上述字段的跨年列举；
- 两期数值的绝对变化和变化率。

数值计算使用 `Decimal`，禁止执行模型生成的表达式。引用对象包含 `chunk_id`、公司、年份、
PDF页码和命中字段附近的原文。

## 解释边界

- 证据消歧规则使用了 Dev 错例迭代，因此100%是开发集成绩，不是最终泛化成绩；
- 30题冻结 Test 没有运行；
- 当前 No-answer 仍以公司/年份越界为主，尚缺“范围内但字段未披露”的困难集；
- 当前是受控字段回答器，不是任意开放问答系统；
- `minimum_reranker_score` 默认未设正阈值，后续需用困难无答案开发集校准。

下一步应新增范围内困难无答案集和证据阈值，再只运行一次冻结 Test，报告最终答案准确率、
引用准确率、误拒答率和漏拒答率。
