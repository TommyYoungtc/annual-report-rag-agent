## 可直接替换的完整项目描述

### 上市公司年报研究 Agent（个人项目，2026.07 – 至今，RTX 4060 Laptop 8GB）

以**评测为中心**的中文年报 RAG/Agent 项目。链路：PDF 解析 → 结构化分块 →
BM25 / Dense 混合召回 → Qwen3-Reranker → 受控工具调用与结构化答案抽取 →
带页码引用的回答 → 离线评测、Oracle 诊断与消融。

- **数据**：宁德时代、科大讯飞、比亚迪、海康威视、美的集团、立讯精密、迈瑞医疗
  2024/2025 共 14 份年报，4,076 页，pypdf 逐页解析后 **6,831 个 Chunk**；
  122 题开发集、30 题困难无答案开发集，以及 32 题公司级冻结盲测。
- **已实现**：结构感知 Markdown 分块；中文单字 + 二元词组 BM25；微调
  BGE-small Dense Retrieval；加权 RRF；公司/年份元数据过滤与章节查询扩展；
  Qwen3-Reranker-0.6B 原生 yes/no-logit 重排；确定性问题路由；8 类财务字段
  Schema 抽取；Decimal 计算；查询约束—证据蕴含拒答；Chunk / 页码 / 原文引用；
  向量缓存；Recall@K / MRR / nDCG / 端到端答案 / 引用 / 拒答分层评测；
  FastAPI + 本地 Web 演示；配置哈希锁和一次性冻结测试门禁；76 个自动化测试。
- **训练与开发结果**：从 48 个训练问题挖掘 1,152 条难负例三元组，在 RTX 4060
  8GB 上微调 BGE-small；12 题留出验证集 Dense Recall@1 从 20.8% 提升到
  91.7%，Recall@10 达到 100%。V2.1 的 122 题 Dev 端到端精确答案、Gold
  Recall@10 和引用准确率均为 100%；30 题困难无答案 Dev 拒答准确率为 100%。
- **真实冻结盲测（32 题，只运行一次）**：

| 指标 | 结果 |
|---|---:|
| 端到端精确答案准确率 | **93.75%（30/32）** |
| 全部 Gold 证据 Recall@10 | **100%（32/32）** |
| 引用 Chunk 精度 / 页码准确率 | 93.75% / 93.75% |
| Gold Oracle 精确答案准确率 | 93.75%（30/32） |

- **防泄露设计**：先在 5 家开发公司上锁定源码、模型、参数和开发结果，再选择从未进入
  Dev 的立讯精密、迈瑞医疗作为公司级留出；两家公司与开发集零重叠；测试标签在配置锁后
  构建、首次模型运行前冻结；预测阶段只接收 query 与检索证据，答案和 Gold Chunk 仅在
  预测后用于计分；冻结测试成功运行一次，运行后未改代码、参数或测试集，也未二次测试。
- **Bad Case 与结论**：两道错误均为立讯精密 2025 年年度指标与分季度指标混淆。
  正确证据已全部进入 Top-10，但 Reranker 将季度页排在年度页之前，答案器分别提取了
  第一季度净利润和现金流。说明当前瓶颈不是召回，而是相似章节判别和证据选择；未来应在
  新测试集上验证章节类型特征或多证据一致性校验，**不能在同一冻结测试集修复后重新报分**。
- **效率与硬件约束**：Embedding 与 Reranker 分时加载，避免两套模型同时占用显存；
  冻结测试中 Reranker 峰值显存 **1,771 MiB**，平均 / P95 重排延迟约
  **1.55 / 2.76 秒**；14 份年报向量索引首次构建约 **8.65 秒**。不训练 7B，
  整条链路可在 RTX 4060 Laptop 8GB 上完成。
- **实验纪律**：区分 Dev、冻结 Test 与 Gold Oracle；保留 20% 的 V1 失败结果和
  93.75% 的 V2.1 真实盲测结果；早期海康威视 / 美的集团的 100% 因参与错误分析而
  降级为 Dev，**不得写成测试集准确率**；简历只填写真实测得且可追溯到锁文件的数字。

- **⚠️ 简历口径**：可以写“公司级冻结盲测端到端准确率 93.75%、检索
  Recall@10 100%”；不可以写“最终准确率 100%”或“支持任意财务字段”。
